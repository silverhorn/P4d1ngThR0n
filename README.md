## 📖 About This Project

This is the beginning of an incredible journey - my son's first steps into the world of robotics at just 6 years old! 🎉

We're using the **Lafvin Tech Arduino kit** to build a Bluetooth-controlled robot from scratch. This repository documents our learning process, experiments, and all the little victories along the way.

**Why we're doing this:**
- 🧠 Learn electronics and programming together
- 🔧 Develop problem-solving skills
- 👨‍👦 Quality father-son bonding time
- 🚀 Inspire other young makers

## 🛠️ Hardware Components

We're using the **Lafvin Tech Robot Car Kit** which includes:

- Arduino UNO R3 board
- L298N Motor Driver
- HC-05 Bluetooth Module
- 4x DC Motors
- Robot chassis
- Wheels and battery holder
- Various sensors (to be added)
- Jumper wires and breadboard

*Detailed component list and part numbers will be added as we progress through testing each module.*

## 💻 Software & Tools

- **Arduino IDE** - Our primary development environment
- **Programming Language:** Arduino (C/C++)
- **Mobile App:** Bluetooth RC Controller (or custom app - TBD)

### Arduino IDE Setup

1. Download Arduino IDE from [arduino.cc](https://www.arduino.cc/en/software)
2. Install USB drivers for Arduino UNO
3. Select **Tools > Board > Arduino UNO**
4. Select correct COM port
